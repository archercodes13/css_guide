HTML + CSS reference

Read the page as a system of containers, relationships and responsive rules.

This guide breaks CSS layout into reusable patterns you can inspect directly in the browser: centered content, full-width colored sections, text beside an image, two cards, project rows, semantic HTML, class placement and mobile transformations. Open DevTools and inspect this page — the page itself uses these rules.

Layout logic

First identify the parent and its direct children. The parent controls how the children are arranged. Each child controls only itself.

Where should classes go?

A class should have a clear job. Do not create a class for every tag, but also do not force one huge class to control everything.

Combining classes

One element can have several classes separated by spaces. The browser applies all matching CSS rules.

.hero = layout .page-width = width + centering
HTML
<section class="split-layout page-width">
    <div class="split-copy">
        <h1>North / South</h1>
        <p>...</p>
    </div>

    <img class="split-visual" src="visual.svg" alt="Visual">
</section>
CSS
.page-width {
    width: 90%;
    max-width: 856px;
    margin: 0 auto;
}

.split-layout {
    display: grid;
    grid-template-columns: 1fr 243px;
    gap: 96px;
    align-items: center;
}

.split-visual {
    width: 243px;
    height: 243px;
    object-fit: cover;
    border-radius: 50%;
}
You do not need class on every line. If an element is unique inside a component, select it through its parent: .split-copy h1 or .media-layout img.
Create a class when the component is reusable, needs a special layout, differs from other elements, or is used by JavaScript.
Use a descendant selector when the element is already clearly identified by its parent, e.g. .panel h3.

How to center the whole page and keep it at 80% width

Usually you do not make the whole body 80% wide. Instead, you create a reusable inner wrapper such as .container. The browser viewport stays full width, while the content inside the container stays centered.

browser / viewport = 100%
.container = 80%
body / viewport = full width .container = centered content

The basic version

CSS
.container {
    width: 80%;
    max-width: 1000px;
    margin: 0 auto;
}
CSS What it means
width: 80% The container uses 80% of the available width.
max-width: 1000px On a very large screen, the content stops growing at 1000px.
margin: 0 auto The left and right automatic margins center the container.
Think of it like this body is the full browser width. .container is the centered content area inside it.

Where do you put the container?

Put it around the content that should share the same centered width. You can reuse the same class in the header, hero, sections and footer.

HTML
<header>
    <div class="container">
        <nav>...</nav>
    </div>
</header>

<main>
    <section class="container">
        <h1>Page heading</h1>
        <p>Content...</p>
    </section>
</main>

<footer>
    <div class="container">
        Footer content
    </div>
</footer>

Here, the header itself is still full width. Only the content inside .container is limited to 80%.

Full-width background, centered 80% content

This is the important pattern when you want a colored section across the whole screen, but the text/cards inside should stay aligned with the rest of the page.

.full-section = 100% wide background
.container = 80%
HTML
<section class="full-section">
    <div class="container">
        <h2>Section heading</h2>
        <p>Centered content...</p>
    </div>
</section>
CSS
.full-section {
    width: 100%;
    padding: 40px 0;
    background: #dfe5dc;
}

.container {
    width: 80%;
    max-width: 1000px;
    margin: 0 auto;
}
Do not put the 80% width on the colored section. If you put width: 80% on .full-section, the background will also become narrow. Put the width on the inner .container instead.

80% vs. 90% vs. fixed max-width

The percentage controls how much empty space you keep at the sides. The max-width prevents long lines on large monitors.

Example Result
width: 80% 10% empty space on each side.
width: 90% 5% empty space on each side.
max-width: 1000px Stops content from becoming too wide.

Mobile

You can keep the same container rule on mobile. If 80% feels too narrow, change it to 90% or 92% inside the media query.

RESPONSIVE CSS
.container {
    width: 80%;
    max-width: 1000px;
    margin: 0 auto;
}

@media (max-width: 700px) {
    .container {
        width: 92%;
    }
}

The container is still centered because margin: 0 auto stays active. Only its percentage width changes.

Full-width sections + centered content

This is one of the most useful patterns in the design. The outer section owns the background. An inner container owns the content width.

The outer section spans the viewport; the inner container does not

.page-width
The text/cards stay centered and limited.

Flex and Grid — the same boxes, different logic

Both can place boxes next to each other. The difference is mainly how you think about the layout: Flex is usually one-dimensional — a row or a column. Grid is two-dimensional — rows and columns.

FLEX

Good for a row that can wrap

North
East
South
West

Flex thinks mainly in one direction. Here the children sit in a row and can wrap when there is not enough space.

GRID

Good for controlled columns

North
East
South
West

Grid explicitly defines the columns. On narrow screens the media query changes two columns into one.

FLEX
.flex-boxes {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
}

.flex-boxes .box {
    flex: 1 1 180px;
}

/* On small screens the items naturally wrap.
   You can also force a column if you want: */

@media (max-width: 700px) {
    .flex-boxes {
        flex-direction: column;
    }
}
GRID
.grid-boxes {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 16px;
}

@media (max-width: 700px) {
    .grid-boxes {
        grid-template-columns: 1fr;
    }
}
Quick decision Use Flex when you mainly think “put these items in a row/column.” Use Grid when you think “I need these exact columns.”

Margin, padding and gap

PropertyMeaningTypical place
paddingSpace inside an element.Section, card, button.
marginSpace outside an element.Between headings/sections/cards.
gapSpace between children of a Flex/Grid parent.The parent.
Padding shorthand
padding: 20px;
/* all sides */

padding: 20px 10px;
/* top/bottom | left/right */

padding: 20px 0 32px;
/* top | left/right | bottom */

padding: 10px 20px 30px 40px;
/* top | right | bottom | left */
Do not use random margins between Flex/Grid children if gap can do the job. The spacing rule belongs to the parent because the parent controls the relationship between the children.

What to measure from a mockup

Be fairly precise with… You can usually estimate…
container width / max-width tiny 1–3px spacing differences
column proportions exact section height if content can define it
major gap and padding values minor border or shadow differences
image aspect ratio / size small decorative details
font-size hierarchy pixel-perfect line breaks
Build the system, not a screenshot. Match the overall proportions and spacing, but let content and responsive rules determine height wherever possible.

CSS property reference for this design

This is the set of properties you are most likely to need to recreate this type of portfolio layout.

Layout

  • display — block, flex, grid, none, inline-block
  • grid-template-columns — define grid columns
  • flex-direction — row or column
  • justify-content — main-axis alignment
  • align-items — cross-axis alignment
  • gap — space between Flex/Grid children
  • order — visual order of Flex/Grid item

Size

  • width — element width
  • max-width — maximum allowed width
  • min-width — minimum allowed width
  • height — fixed height
  • min-height — minimum height
  • max-height — maximum height
  • min() / calc() — responsive calculations

Spacing

  • margin — outside space
  • margin-inline — left/right logical margin
  • margin-bottom — outside space below
  • padding — inside space
  • padding-top/bottom — targeted inside spacing
  • gap — controlled repeated spacing

Responsive media

  • max-width: 100% — prevent overflow
  • height: auto — preserve aspect ratio
  • object-fit: cover — crop without distortion
  • border-radius — rounded/circle image
  • display: block — remove inline image baseline gap

Type and hierarchy

  • font-family — typeface
  • font-size — text size
  • font-weight — thickness
  • line-height — line spacing
  • color — text color
  • text-align — left/center/right
  • text-decoration — underline etc.

Surface / decoration

  • background — background color
  • border — outline
  • border-bottom — separator line
  • border-radius — rounded corners
  • box-shadow — shadow
  • cursor: pointer — clickable cursor

Positioning / layers

  • position: relative — reference for positioned children
  • position: absolute — remove from normal flow and position precisely
  • position: sticky — stay visible while scrolling
  • top/right/bottom/left — position offsets
  • z-index — layer order

Responsive / useful

  • @media — conditional styles by viewport
  • box-sizing: border-box — predictable sizing
  • overflow-x: auto — local horizontal scroll when needed
  • scroll-behavior: smooth — smooth anchor movement
  • :hover — pointer interaction state

What 1fr means

fr is a fraction of the available Grid space. repeat(2, 1fr) means two equal columns. 246px 1fr means a fixed 246px first column and a flexible second column.

Why box-sizing: border-box is worth using

CSS
* {
    box-sizing: border-box;
}

Padding and border are included inside the width you set. A 300px element with padding stays 300px wide instead of unexpectedly becoming wider.

Debugging notes

ProblemCheck this
gap does nothingThe parent must normally be display: flex or display: grid.
order does nothingThe item must be a child of a Flex/Grid parent.
The page is not centeredGive the container a width/max-width and margin: 0 auto.
The blue background is only in the middleYou probably put the background on the constrained container instead of the outer section.
An image stretchesUse object-fit: cover for a fixed box or height: auto for a fluid image.
Cards overflow on mobileChange multi-column Grid to 1fr in the media query.
Mobile CSS seems ignoredCheck the viewport meta tag and make sure the media query comes after the base rule.
A 100% width element is still too wideUse box-sizing: border-box and inspect padding/borders.
Debugging question “Which element should control this?” If it is about the relationship between several elements, inspect the parent. If it is only about one item, inspect that child.
